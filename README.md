#  Dating Platform — Backend

An ongoing full-stack dating platform project focused on building the backend infrastructure for user authentication, profile management, matching, and real-time communication.

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Backend:** Express.js
- **Database:** MongoDB
- **Real-Time Communication:** Socket.IO
- **API Architecture:** REST APIs

🚧 **Status:** Under active development.

This project is being built to explore backend architecture, authentication, real-time systems, and the engineering challenges involved in creating a modern dating platform.
